# Macro Vision

Macro Vision giúp tự động hóa thao tác bàn phím và chuột trên Windows. App theo dõi vùng màn hình bạn chọn; khi hình ảnh khớp điều kiện đã thiết lập, app thực hiện các thao tác trong script.

Tạo điều kiện bằng cách chụp vùng màn hình cần nhận diện, thêm thao tác phím hoặc chuột, rồi nhấn **Bắt đầu**. Dùng **F6** để bắt đầu, **F7** để tạm dừng/tiếp tục và **F8** để dừng.

Dùng **Mở script** và **Lưu script** để mở hoặc lưu cấu hình. Macro gửi đầu vào mô phỏng; ứng dụng đích có thể không nhận hoặc xử lý chúng.
